<summary><strong>🧪 Open the lab: a proposed AI extension to my resume builder</strong></summary>

### Resume Intelligence — project concept

An extension that could help a user compare their resume with a job description and understand which requirements are supported by their experience.

1. **Prepare the text:** extract skills and experience from the resume and job description.
2. **Start with a baseline:** compare keyword matching with semantic similarity.
3. **Explain the result:** show supporting text and gaps instead of presenting an unexplained score.
4. **Evaluate:** test on varied examples and inspect false matches.
5. **Integrate:** present suggestions through the existing Django interface, with user control over edits.

**Design principle:** help people describe real experience clearly; never invent qualifications or claim to predict hiring outcomes.

*This is a proposed extension, not a completed project.*
